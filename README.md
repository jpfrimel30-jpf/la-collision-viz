# Los Angeles Car Crash Analysis — Visualization

An interactive data visualization built with React, exploring logistic regression predictions on 621,000 LA car crash records spanning 2010–2024.

**Live site:** [la-carcrash.com](https://www.la-carcrash.com)

**Analysis and data pipeline:** [github.com/jpfrimel/la_collisions](https://github.com/jpfrimel/la_collisions)

---

The site includes an interactive prediction model, crash scenario explorer, findings and process walkthrough, and a Mapbox map of all recorded crashes across Los Angeles.

---

Built with React and deployed on Vercel. The vast majority of the code was written with [Claude Code](https://claude.ai/code), Anthropic's AI coding assistant, under my direction and oversight.
